LeetCode 55：「跳跃游戏」（Jump Game）是经典的**贪心算法**问题，题意简单但有技巧。

------

### 🧾 题目描述：

给定一个非负整数数组 `nums`，其中 `nums[i]` 表示你在第 `i` 个位置最远可以跳跃的步数。

判断你是否能够**到达最后一个位置**。

------

### 🧠 解题思路：

#### 方法一：贪心算法（推荐 ✅）

维护一个变量 `maxReach` 表示当前能够跳到的最远下标。

遍历数组：

- 如果当前位置 `i > maxReach`，说明无法到达当前位置，直接返回 `false`
- 每次更新 `maxReach = max(maxReach, i + nums[i])`
- 如果 `maxReach >= nums.length - 1`，说明可以到达终点，返回 `true`

------

### ✅ Java 示例代码（贪心）：

```
java复制编辑public class Solution {
    public boolean canJump(int[] nums) {
        int maxReach = 0;
        for (int i = 0; i < nums.length; i++) {
            if (i > maxReach) return false;
            maxReach = Math.max(maxReach, i + nums[i]);
        }
        return true;
    }
}
```

------

### 🧪 示例解析：

```
text复制编辑输入: [2,3,1,1,4]
过程:
i = 0, maxReach = max(0, 0+2) = 2
i = 1, maxReach = max(2, 1+3) = 4
i = 2, maxReach = max(4, 2+1) = 4
maxReach >= 4 → ✅可达

输出: true
```

------

### ❌ 反例示例：

```
text复制编辑输入: [3,2,1,0,4]
过程:
i = 0, maxReach = 3
i = 1, maxReach = max(3,1+2)=3
i = 2, maxReach = max(3,2+1)=3
i = 3, maxReach = max(3,3+0)=3
i = 4 > maxReach → ❌ 不可达

输出: false
```
